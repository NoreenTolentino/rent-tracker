# Rent Tracker UI

A boarding house rent ledger dashboard built with plain HTML and CSS. No JavaScript or frameworks.

**Live Site:** https://noreentolentino.github.io/rent-tracker/

## Features

- Monthly summary of expected, collected, and outstanding rent
- Reminder panel for overdue and due-today tenants
- Tenant ledger with status badges
- CSS-only status filter (All, Paid, Unpaid, Overdue)
- Responsive layout that turns the table into cards on mobile
